Author: 李宗阳 | LangSplat Reproduction & Visualization Demo

项目简介

本项目基于 LangSplat 框架开展开放词汇三维场景理解实践。项目使用 Canon R50 采集桌面多视角图像， 通过 COLMAP 完成相机位姿估计与稀疏重建，并在 Vanilla 3DGS 重建结果基础上引入 SAM / CLIP 提取二维视觉语言特征，进一步训练三维语言特征场，实现基于文本 prompt 的三维目标检索与高亮可视化。

1. 原始数据采集

该部分展示自采桌面场景的原始视频数据。场景包含书本、充电宝、蓝色毛绒玩具、握力器等典型物体， 用于后续多视角重建、3DGS 训练和开放词汇语义查询实验。

2. 3DGS 三维场景可视化

该部分展示由 3D Gaussian Splatting 表示的三维桌面场景。浏览器端支持对重建结果进行旋转、缩放和平移， 便于观察场景结构和重建效果。

操作提示：鼠标左键旋转，滚轮缩放，右键平移。若模型加载失败，请检查 my_desk.splat 是否已正确上传。

3. 渲染质量对比

该部分对比真实图像视角下的 Ground Truth 与 Vanilla 3DGS 渲染结果，用于展示 3DGS 在该场景中的外观重建效果。

4. 开放词汇语义查询

在三维语言特征场训练完成后，系统可以根据文本 prompt 对三维场景中的目标区域进行查询和高亮。 下方展示不同文本查询对应的可视化结果。

注：高亮结果主要用于展示开放词汇语义定位效果，不等同于精细实例分割或物体编辑结果。

5. 项目小结

本项目重点在于打通自采数据、COLMAP 几何初始化、Vanilla 3DGS 预训练、SAM / CLIP 语义特征提取、 三维语言特征场训练与文本查询可视化的完整流程。该实践帮助我进一步理解从多视角图像重建到三维语义场构建的基本路径， 也为后续学习三维重建、开放词汇场景理解和空间智能相关方向提供了工程基础。

几何重建基础

通过 COLMAP 位姿估计和 Vanilla 3DGS 场景表示，理解多视角图像到三维场景表达的基础流程。

视觉语言特征迁移

通过 SAM / CLIP 特征提取与三维语言特征场训练，实践二维语义信息向三维场景中的迁移过程。

开放词汇三维查询

基于文本 prompt 对场景中的目标区域进行查询和高亮，展示开放词汇三维语义理解的基本能力。

后续方向

后续希望进一步学习三维重建、3DGS、视觉语言模型和空间智能相关方法，并探索其在测绘遥感场景中的应用。
